# Pragma 开源许可与商标边界

> 文档状态：已采用  
> 更新日期：2026-09-23

## 1. 当前许可

当前仓库中的 Pragma 项目代码使用 [GNU Affero 通用公共许可证第 3 版，仅此版本（AGPL-3.0-only）](../../LICENSE)。根 `LICENSE` 文件包含 GNU 发布的完整许可文本；SPDX 标识为 `AGPL-3.0-only`。

AGPL-3.0 允许个人和组织使用、修改、复制、分发代码，也允许商业使用和运营托管服务。接收者必须遵守 AGPL 条款，主要包括：

- 传递程序或其修改版本时，附上许可证并保留所需的版权和归属声明；
- 以目标代码形式传递时，按许可证提供对应源代码的获取方式；
- 修改程序并让用户通过网络远程交互时，向这些用户显著提供免费获取该修改版本对应源代码的机会。

AGPL 不要求运营者事先向 Pragma 项目申请托管服务或商业嵌入授权。它通过源码提供义务保障用户对修改版本的自由，而不是禁止商业运营。具体权利义务以 `LICENSE` 正文为准。

本许可适用于当前仓库树。此前发布的版本仍按该版本发行时附带的许可证处理，除非其权利持有人另行授予 AGPL 权利。

## 2. 贡献

有意提交并纳入 Pragma 的贡献按照 AGPL-3.0-only 发布，符合 AGPL 第 5 节。除此之外，贡献者会按 [`CONTRIBUTING.md`](../../CONTRIBUTING.md) 向 Project Steward 授予额外的使用、再许可和重新许可贡献的权利。这项单独授权不限制接收者依据 AGPL-3.0-only 已获得的权利。

Project Steward 是 [`TRADEMARKS.md`](../../TRADEMARKS.md) 中定义的 Pragma canonical repository 所有者，或该仓库明确指定的继任者。

## 3. 商标与品牌

AGPL-3.0-only 不授予使用 Pragma 名称、Logo、产品名或暗示官方背书的权利。品牌使用由 [`TRADEMARKS.md`](../../TRADEMARKS.md) 单独管理：

- 可以准确说明软件“基于 Pragma”或“兼容 Pragma”；
- 修改版不得冒充官方 Pragma 发行版，也不得暗示项目赞助或认可；
- 法律归属与许可证声明应按许可证保留，修改版可以使用自己的产品名称和视觉标识。

## 4. 文件与发布元数据

- 根 [`LICENSE`](../../LICENSE) 保存 GNU AGPL-3.0 正文；
- 根 `package.json` 和 CLI 发布包使用 SPDX 标识 `AGPL-3.0-only`；
- README、贡献指南、`NOTICE` 和策略文档说明当前许可；
- 单独带有许可证声明的第三方组件仍按其各自许可证管理。
