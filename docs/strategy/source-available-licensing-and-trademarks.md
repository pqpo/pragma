# Pragma 源码可用许可证与商标边界

> 文档状态：已采用
> 更新日期：2026-07-26

## 1. 当前决策

Pragma 已采用 [Pragma Source Available License 1.0](../../LICENSE)，并使用广泛的第三方服务限制：
不仅禁止未经授权的第三方 Pragma 托管服务，也禁止将 Pragma 嵌入面向第三方销售、许可或商业分发的
产品与服务。

许可证允许：

- 查看和研究源代码；
- 修改源代码；
- 个人和组织内部使用；
- 在自己的环境中自托管；
- 在遵守许可证和归属要求的前提下分发代码及修改版。

许可证禁止：

- 未经书面授权，将 Pragma 或其主要功能作为面向第三方的 SaaS、托管服务或管理服务提供；
- 以白标方式向第三方提供对 Pragma 主要功能、API 或用户界面的访问；
- 未经书面授权，将 Pragma 作为组件嵌入面向第三方销售、许可或以其他方式商业分发的产品或服务；
- 删除或遮蔽许可证、版权及其他法律归属声明；
- 冒充官方 Pragma 产品、发行版或服务。

该限制不符合 OSI 对开源软件“可以用于任何领域”的定义，因此 Pragma 应准确表述为“源码可用”，
不能表述为“OSI 开源”或使用 OSI Approved 标识。

## 2. 许可证结构

Pragma 参考“Apache-2.0 基础条款 + 项目补充条件”的结构：

```text
Pragma Source Available License
= Apache License 2.0 基础权利与义务
+ Pragma Additional Conditions
```

Apache-2.0 提供：

- 使用、复制、修改和分发的基础版权许可；
- 明确的专利授权与专利诉讼终止机制；
- 再分发、修改声明、`LICENSE` 和 `NOTICE` 的基础要求；
- 不授予项目商标、商号和产品名使用权的边界。

Pragma Additional Conditions 包括：

1. 禁止未经书面授权的第三方 Pragma SaaS、托管服务和管理服务；
2. 禁止以白标方式向第三方提供 Pragma 的实质性功能集合；
3. 禁止将 Pragma 嵌入面向第三方销售、许可或商业分发的产品或服务；
4. 不得删除或遮蔽许可证、版权和法律归属声明；
5. 官方 Pragma 前端和发行版不得删除或修改官方 Logo 与版权信息；
6. 修改版必须显著说明已经修改，并遵守独立商标政策。

增加这些限制后，最终文件不再是标准 Apache-2.0，也不能使用 `Apache-2.0` 作为许可证标识。对外应称为
“基于 Apache-2.0 条款的 Pragma Source Available License”。

根 `LICENSE` 清楚区分补充条件和完整 Apache-2.0 基础文本，并规定发生冲突时补充条件优先。

## 3. “禁止第三方 SaaS”的边界

许可证采用广泛限制，同时覆盖直接提供 Pragma 能力和将 Pragma 嵌入第三方商业产品两类情况。

典型禁止场景：

- 第三方运营一个 Pragma 托管平台；
- 第三方将 Pragma 换名或换 Logo 后作为自己的 Agent 编排 SaaS；
- 客户可以通过第三方服务访问 Pragma 的主要 API、管理界面或执行能力；
- 第三方以 MSP 形式持续运行并向一个或多个客户提供 Pragma 服务；
- 第三方将 Pragma 作为后台组件嵌入其收费 SaaS，即使客户不能直接访问 Pragma 的界面或 API；
- 第三方把包含 Pragma 的产品或服务销售、许可或以其他方式商业分发。

托管服务限制不以是否收费为前提。只要第三方在自己的环境中运行 Pragma，并把相关服务提供给其他
主体，就属于需要书面授权的范围。

典型允许场景：

- 个人在自己的设备上运行；
- 组织在自身控制的环境中仅为内部业务使用，包括多个内部 workspace；
- 组织修改 Pragma 供自身内部使用，不向其他主体提供托管服务或商业分发；
- 在许可证允许的范围内研究、评估和贡献代码。

客户环境部署、系统集成、经销、OEM、白标、MSP 和其他边界场景是否属于内部使用，应以许可证定义和
书面授权为准，不能仅因为代码运行在客户环境中就自动视为允许。

## 4. 商标与许可证分开治理

源码许可不自动授权 Pragma 名称、Logo、产品名或官方背书。

具体规则由 [`TRADEMARKS.md`](../../TRADEMARKS.md) 管理：

- 第三方可以如实说明“基于 Pragma”或“兼容 Pragma”；
- 修改版不得冒充官方 Pragma 发行版；
- 未经许可不得使用 Pragma 名称或 Logo 作为第三方产品、服务或域名的品牌；
- 法律归属声明与用户界面品牌是不同概念；
- 修改版可以采用自己的品牌，但不得删除许可证要求保留的法律声明。

## 5. 外部贡献

禁止第三方 SaaS 意味着项目可能需要针对特定主体授予书面例外。若外部贡献的版权分散，项目可能无权
为完整代码库授予例外许可。

`LICENSE` 第 2.7 节已包含贡献授权：贡献者向 Project Steward 授予使用、修改、分发、再许可和以
其他条款重新许可贡献所需的权利。贡献者可以在提交前将材料明确标记为 `Not a Contribution`。
