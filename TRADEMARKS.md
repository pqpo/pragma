# Pragma Trademark Policy

## Purpose

The source code license and the Pragma brand are separate. Permission to use, modify, or distribute
Pragma source code does not grant permission to use the Pragma name, logos, product names, or other
distinctive brand features (the "Pragma Marks"), except as allowed by applicable law or this policy.

The Pragma Marks are managed by the Project Steward defined in [`LICENSE`](./LICENSE).
This policy does not claim that any Pragma Mark is registered.

## Uses That Do Not Require Additional Permission

Subject to applicable law, you may:

- use the word `Pragma` to truthfully refer to the unmodified official project or link to its
  official repository;
- state that your software is "based on Pragma," "a fork of Pragma," or "compatible with Pragma"
  when that statement is accurate;
- retain copyright, license, source-origin, and `NOTICE` statements required by the source code
  license;
- display unmodified Pragma Marks already included in an Official User Interface when their
  retention is required by the source code license;
- discuss the project in articles, documentation, reviews, and community conversations.

These uses must not imply that your project, product, or service is published, sponsored, endorsed,
or certified by the Pragma project.

## Uses That Require Prior Written Permission

Unless applicable law permits the use without permission, you must obtain prior written permission
to:

- use a Pragma Mark, or a confusingly similar name, as part of the name of a product, service,
  company, organization, domain, package, application, or distribution;
- use a Pragma logo except for the limited retention required by the source code license;
- use a modified version of a Pragma logo;
- present a modified distribution as an official Pragma release;
- use a Pragma Mark in a way that suggests sponsorship, endorsement, certification, or official
  status;
- use a Pragma Mark on merchandise or promotional goods.

## Forks and Modified Distributions

You may modify and redistribute the source code according to its source code license. A modified
distribution must use a distinct product name and visual identity unless written permission says
otherwise.

You may truthfully describe the distribution as being based on Pragma, provided that the description
is less prominent than your own name and is accompanied by a clear statement such as:

> This project is based on the Pragma project and is not affiliated with or endorsed by the official
> Pragma project.

Do not remove copyright, license, attribution, or `NOTICE` text that the source code license requires
you to retain. Removing Pragma branding from a modified product does not permit removal of those
legal notices.

## No Modification of the Marks

Permission to use a Pragma Mark does not include permission to alter, abbreviate, translate, combine,
or create a confusingly similar variation of the mark unless separately agreed in writing.

## Requests

Open a repository issue containing a non-confidential description of the proposed use. Do not
include confidential business information in a public issue.

The project may grant exceptions in writing. Any exception applies only to the specific use that was
approved.
