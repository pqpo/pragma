# Historical environment-sync manifests

These YAML files were emitted by the Git sync providers in historical checkouts, rather than
constructed from current schemas with an older version string.

- `knowledge-*-v1.yaml` and `skill-*-v2.yaml`: `origin/main` at `c6ae5612`.
- `skill-*-v1.yaml`: commit `5e61bc90`, when the Skill provider wrote protocol v1.

Each fixture was generated by creating an empty bare Git repository, calling that checkout's
`createGitContextStoreSyncProvider` or `createGitSkillSyncProvider` to publish one asset, and
extracting the resulting manifest files from the Git commit. The test covers adjacent and chained
upgrades, current-version no-op, and future-version rejection.
