# Support

Pragma is under active development. Community support is best-effort and does not currently include
guaranteed response or resolution times.

## Where to Ask

- Use a **bug report** for reproducible product or code defects.
- Use a **feature request** for a concrete user problem or capability proposal.
- Use a pull request for a focused, reviewed change after reading
  [CONTRIBUTING.md](./CONTRIBUTING.md).
- Use private vulnerability reporting for security issues as described in
  [SECURITY.md](./SECURITY.md).

Before opening an issue:

1. search existing issues;
2. confirm the behavior on the current `main` branch when practical;
3. reduce the problem to the smallest reproducible case;
4. remove credentials, personal data, proprietary files, and sensitive logs.

## What to Include

Useful reports include:

- Pragma commit or release;
- operating system, Node.js version, and pnpm version;
- affected app, package, Runtime Adapter, or plugin;
- expected and actual behavior;
- reproducible steps;
- redacted logs or a minimal repository;
- whether the problem is deterministic.
